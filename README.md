Welcome to my **Data Structures & Algorithms class archive**.

This repository contains the code, implementations, practice questions, concepts, experiments, and problem-solving work I build throughout my DSA lectures.

Instead of keeping everything scattered across:


# ⚡ COMPLEXITY MINDSET

One of the biggest goals of this archive is learning to think about **efficiency**, not just correctness.

```text
O(2ⁿ)
  ↓
O(n²)
  ↓
O(n log n)
  ↓
O(n)
  ↓
O(log n)
```

For every important problem, I try to understand:

### ⏱️ Time Complexity

How does runtime grow as input size increases?

### 💾 Space Complexity

How much additional memory does the solution require?

### 🧠 Pattern

What technique can be reused on another problem?

This repository is not about having the biggest number of solved problems.

